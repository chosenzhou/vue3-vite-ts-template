# H5 模板工程指南

本指南描述当前模板的模块边界和扩展方式。范围及认证取舍见 [ADR-0008](./adr/0008-generic-h5-starter-scope.md) 和 [ADR-0009](./adr/0009-password-authentication-contract.md)；启动及接口字段以 [README](../README.md) 为准。

## 目录与方法归属

| 位置                          | 职责                                                | 典型修改                         |
| ----------------------------- | --------------------------------------------------- | -------------------------------- |
| `src/main.ts`                 | 安装应用插件，连接 HTTP 失效通知与会话、导航        | 增加应用级插件或调整失效后的导航 |
| `src/App.vue`                 | 最小应用壳、恢复中的等待与失败重试界面              | 调整全局壳或恢复反馈             |
| `src/router/index.ts`         | 路由、登录守卫、标题、待恢复的目标地址              | 增加业务路由及访问约束           |
| `src/services/http.ts`        | alova 客户端、凭证注入、HTTP 错误及失效通知         | 修改通信协议或错误解析           |
| `src/services/api/`           | 接口地址、参数及返回类型                            | 对接新后端接口                   |
| `src/services/auth.ts`        | `signIn`、`restoreSession`、`signOut`、失效会话处理 | 调整登录和会话生命周期           |
| `src/stores/session.ts`       | token、用户资料、会话验证状态和版本                 | 调整会话数据与本地 token 存储    |
| `src/services/model/`         | API 与应用共享的显式类型                            | 扩展用户资料或接口模型           |
| `src/views/`                  | 页面表单、加载、错误反馈和页面导航                  | 添加或修改业务页面               |
| `src/utils/redirect.ts`       | 站内返回地址校验                                    | 调整可接受的登录返回地址         |
| `src/config.ts`               | 前端请求与 Vite 共用的 API 基址解析                 | 修改默认值或基址校验             |
| `src/types/`                  | 环境声明和框架类型扩展                              | 扩展路由 meta 或请求 metadata    |
| `src/assets/styles/main.scss` | 应用基础样式与响应式内容区                          | 修改全局间距和内容宽度           |
| `src/quasar-variables.scss`   | Quasar 主题变量                                     | 调整主题色                       |

API 方法只描述通信契约，不操作路由或会话。请求客户端通过 `configureHttpAuth` 接收凭证读取、版本读取及失效通知，保持对 Router、Store 和业务 API 的独立性。认证模块使用 API 与会话 Store，导航由页面、守卫和应用初始化完成。

ESLint 的 `template/module-boundaries` 自动检查这些直接依赖：HTTP 客户端不引用路由、Store 或业务服务；API 不引用路由、Store 或认证协调层；认证协调层不引用路由。检查覆盖别名、相对路径、转导出和字符串动态导入，初始化层仍可连接这些模块。新增边界时同时更新规则及工具回归用例。

当前规模保持集中路由。出现真实复用需求后再创建公共组件或布局；包含 Vue 响应式、生命周期的复用逻辑归入 composable，无业务副作用的纯函数归入工具模块。直接使用 Quasar，不为每个组件增加同名包装。

## 会话边界

会话状态区分匿名、有待验证凭证、恢复中、已验证。`loggedIn` 从已验证状态派生；页面使用认证入口更新会话，避免分别拼装 token、用户和登录状态。

`signIn` 仅在发起时的会话版本仍有效时保存登录结果并返回 `true`；退出或新会话使旧请求过期时返回 `false`。调用页面仅在返回 `true` 后继续登录成功导航，避免旧请求恢复身份或触发过时跳转。

启动守卫需要等待凭证验证时，应用壳仍可显示恢复反馈。验证成功放行；401 结束会话；网络和服务端故障保持待验证状态，显示重试并保留原目标。

请求默认关闭 alova GET 缓存和请求共享；当前用户请求也关闭浏览器 HTTP 缓存。认证模块只合并同一会话版本的恢复，失效通知使用请求发出时版本，旧响应不能覆盖新会话。后续业务如需缓存，应明确其身份隔离和失效策略。

## 添加业务页面

1. 在 `views` 中增加页面，通过现有 Quasar 组件实现界面和局部交互。
2. 注册路由，设置名称和标题；需要登录的页面添加 `requiresAuth`。未标记的路由公开。
3. 接口调用放在 API 模块，页面处理 loading、错误和重试。跨页面确实共享的状态再加入 Pinia。
4. 用真实页面和 HTTP 拦截验证新增行为；无需依赖真实账号测试常规流程。

登录页先验证返回地址，再确认它能匹配实际路由；增加页面后无需添加另一套返回地址列表。未知地址继续由公开 404 处理。

## 添加或替换 API

接口模型显式导出，用户资料与登录响应分开。新增 API 使用既有 `request`，返回后端真实结构；需要适配响应包裹层时，在明确的通信或接口边界处理。

受保护请求默认注入 Bearer token。登录等应独立处理认证错误的请求使用 `meta.auth = false`，同时跳过自动凭证和全局 401；退出请求先捕获 token，再使用显式 Authorization，因为本地会话会立即清理。

HTTP 错误可通过导出的 `ApiError` 读取状态与响应体。业务页面根据需要显示错误；不要在每个 API 方法中复制清会话和跳转逻辑。

## 接入平台能力

具体项目需要微信或企业微信能力时，再安装对应 SDK，并将签名接口与初始化放在明确的平台集成模块。需要页面响应式状态时才包装为 composable；平台 Secret 和签名凭证由后端持有。

如果平台接入改变了登录方式，应调整统一认证入口、路由和后端契约，并补对应测试；通用 HTTP 客户端继续只负责通信。

## 验证边界

现有 E2E 运行真实页面、路由、HTTP 客户端和 localStorage，只在 HTTP 边界拦截响应。主要断言用户可见反馈、地址、请求契约和会话持久化结果，不替换内部 Store 或认证方法。

并发和迟到响应等难以从最小页面触发的行为，使用少量公共模块入口测试；不增加生产测试按钮或新的测试框架。文档、配置和依赖清理通过内容、链接、安装及构建检查验证，避免为文件移动编写镜像测试。

新增行为通过既有类型检查、lint、构建及受影响 E2E 后，再运行完整套件。测试运行方式和独立端口说明见 README。

## 任务上下文与验证

拆分独立任务时，用短上下文指针提供规格、单票、必要 ADR 或研究记录，并明确工作目录、分支基点、负责范围、测试边界及独占端口。入口材料应足以独立完成任务；仅当决策尚未落盘且无法由入口恢复时，才补充相应对话背景。此约定不自动授权创建代理或并行执行。

委派时优先传递这些入口，避免默认复制整段会话。任务完成后返回提交、实际验证结果、必要的失败到通过证据和剩余限制；合入依赖票后重新计算可执行任务，不用定时查询代替交付通知。

每个切片先运行相关检查；最终组合运行完整检查。相同代码和环境已通过的验证无需反复重跑，只有新代码、合并冲突、失败或新疑点才扩大验证。进度更新说明新证据及剩余事项，审查按[审查标准](../CODING_STANDARDS.md)进行。
