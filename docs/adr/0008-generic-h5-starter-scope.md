# 通用 H5 最小模板的范围与复用方式

模板面向普通浏览器中的 H5 应用，不再限定企业微信工作台；企业微信、微信等平台的 JS-SDK 由具体项目按需接入。相比预装平台能力，这一选择减少新项目需要理解和移除的约定；本决策取代 ADR-0005，并取代 ADR-0001 中仅支持企业微信客户端的范围限制，保留其标准 Vue H5 技术方向。

新项目复制模板后独立开发，模板后续修复按需手动同步，当前不建立需要下游持续升级的公共基础包。

默认保留 Vue、TypeScript、Vite、Vue Router、Pinia、Quasar、SCSS 和 alova；移除 ECharts、vue-echarts 及图表示例。认证保留普通账号密码登录的请求方法、登录回调、登录守卫和用户会话，不随平台 SDK 一并删除。

以上定位于 2026-11-13 讨论中确认；账号密码认证契约见 [ADR-0009](./0009-password-authentication-contract.md)。模块归属与扩展方式见[工程指南](../development.md)。
