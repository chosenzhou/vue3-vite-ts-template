# WeCom Workbench H5 Template

A browser-based Vue application for WeCom self-built agents opened from the Workbench.

## Language

**WeCom H5**:
A web application running in a WeCom built-in browser and associated with a corp and self-built agent.
_Avoid_: 企业微信网页, WeChat Work H5

**Self-built Agent**:
An application created by an enterprise inside WeCom and exposed through Workbench, message cards, or other WeCom entry points.
_Avoid_: 应用号, 公众号应用

**Workbench**:
The WeCom surface where members discover and open enterprise applications.
_Avoid_: 工作台应用, 桌面端

**Development Browser**:
An ordinary browser used only for local development and debugging; it is not a supported production client.
_Avoid_: fallback client

**工作台首页 (Workbench Home)**:
本销售数据平台的首页，提供月度概览和各数据模块的入口。与企业微信用于发现和打开应用的 Workbench 承载入口区分。
_Avoid_: 销售数据看板

**销售数据看板 (Sales Dashboard)**:
从工作台首页进入的销售分析页面，按今日、本周或本月展示销售额、订单量、目标完成率、品类销售结构与重点客户排名。
_Avoid_: 工作台首页
